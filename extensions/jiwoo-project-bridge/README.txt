지우 프로젝트 연결 1.1.0 (PC 크롬)

1. 내려받은 ZIP을 압축 해제한다.
2. 크롬 주소창에 chrome://extensions 를 입력한다.
3. 오른쪽 위 개발자 모드를 켠다.
4. '압축해제된 확장 프로그램을 로드합니다'를 누르고 manifest.json이 들어 있는 폴더를 선택한다.
5. 같은 크롬에서 ChatGPT에 로그인하고 캐릭터 라이브를 새로고침한다.
6. 지우 채팅 상단의 '대화내용 업데이트'를 누른다.

버튼을 누를 때만 앱에서 지정한 한지우의 01 → 02 → 03 원본 대화를 순서대로 열어 화면의 텍스트를 읽는다.
프로젝트 연결에서 각 채팅방만 따로 업데이트할 수도 있다.
이전 버전이 있다면 같은 폴더에 새 파일을 풀고 chrome://extensions에서 이 확장 프로그램의 새로고침을 누른다.
앱도 새로고침하면 연결 프로그램 1.1.0이 연결됐다는 표시가 나온다.
로그인 비밀번호·쿠키·API 키를 읽거나 저장하지 않는다. ChatGPT에 메시지를 전송하지 않는다.
읽은 내용은 로그인된 캐릭터 라이브에만 전달하며, 다른 전송 서버는 사용하지 않는다.
ChatGPT에서 이전 메시지가 끝까지 로드되지 않으면 앱이 '최근 기록만 확인'으로 표시한다.
한 번 PC에서 업데이트한 맥락은 아이폰 앱에서도 이어서 사용한다.
아이폰 단독 자동 가져오기는 지원하지 않는다. 수동 JSON 가져오기는 앱에서 사용할 수 있다.
앱에서 진행한 내용을 ChatGPT에 다시 반영하려면 'ChatGPT로 이어가기 복사'로 복사 후 원본 대화에 붙여 넣는다.
