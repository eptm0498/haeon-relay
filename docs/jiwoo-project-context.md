# 지우의 고정 대화 기억

기존 업데이트 버튼, 가져오기 API, 크롬 연결 프로그램, ZIP 배포와 설치 안내는 제거했다. 앱이 ChatGPT에 접속하거나 원본 대화를 수정하는 기능은 없다.

지우는 현재 ‘한지’ 프로젝트 ‘01’을 한 번 확인해 정리한 비공개 기억을 사용한다. 이전 ‘한지우’ 프로젝트의 01·02·03은 별개 세계관이며 사용하지 않는다. 원문과 출처는 비공개 DB에 두고 공개 저장소에 올리지 않는다.

`private.live_story_archive`는 원문, 확인 시점, 사건별 사실과 출처, 최신 상태, 지우 자신의 발화 예시를 보관한다. 서버의 `live_story_memory` RPC는 서버 권한을 확인한 뒤 출력에 필요한 기억만 읽는다. 변경 기능은 없다. 캐릭터별 앱 대화 기록과 섞어 쓰거나 다른 캐릭터에게 제공하지 않는다.

실시간 채팅·음성, 일반 답장, 선톡·연속 메시지에서 같은 기억을 적용한다. 전체 사건 목차·정리된 모든 사건·최신 상태를 제공하고, 질문과 관련된 비공개 원문 발췌와 발화 예시를 함께 제공한다. 기록에 없는 사건은 만들어 회상하지 않는다. 라이브에서 이후 직접 나눈 대화는 기존 앱 기억으로 이어간다.

현재 지우의 실제 말끝·생략·반응·호칭을 참고한다. 행동에 담긴 다정함은 짧은 직접 발화로 옮기며 상담·시적 독백·과한 애교로 바꾸지 않는다. 글에서도 지우의 대사만 표시한다. 음성은 자음·이모지·지문·타인의 대사를 읽지 않는다. 잘못된 소설 형식이 생성되면 출력 전에 한 번 교정하고 여전히 지문이 남으면 전송하지 않는다.

검증은 `node --test tests/project-context.test.mjs tests/reply-jobs.test.mjs`, 타입 검사와 빌드를 사용한다. `[verify-jiwoo]` 커밋은 저장되지 않는 합성 질문으로 실제 Gemini 응답과 ElevenLabs 승 음성, 제거된 API·ZIP의 접근 불가를 확인한다. 원문·자격 증명·오디오는 로그에 남기지 않는다.
