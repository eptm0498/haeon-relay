# 지우 프로젝트 연결

지우는 기존 캐릭터를 바꾸지 않고 별도 DB 행으로 추가한다. 지침과 대화 원문은 비공개 DB에만 저장하며 저장소에 넣지 않는다. 고2 세계관을 현실 사용자 프로필과 분리한다.

## 이어받기

- 지우 화면의 **대화내용 업데이트**는 PC 크롬 연결 프로그램을 통해 연결된 ChatGPT 대화의 화면 텍스트를 읽는다. ChatGPT 비공개 API·인증 쿠키·비밀번호는 사용하지 않는다.
- 최초 설치가 필요하다. `npm run build` 전에 연결 프로그램 ZIP이 자동 생성되며 `/jiwoo-project-bridge.zip`에서 내려받을 수 있다.
- 아이폰 단독 자동 가져오기는 지원하지 않는다. PC에서 반영한 맥락은 아이폰에서도 같은 서버 기억을 사용한다. JSON·화자 구분 TXT 수동 가져오기도 제공한다.
- 연결 대상은 같은 한지우 프로젝트의 01 → 02 → 03 원본 대화다. 03이 최신이다. 주소는 비공개 DB에만 등록하며 다른 프로젝트·계정·미지정 채팅을 검색하지 않는다. 공유 스냅샷 대신 확인된 프로젝트 원본 주소를 사용한다.
- 전체 로드에 실패하면 최근 창만 반영했다는 상태를 명시한다. 불완전한 화면을 전체 기록으로 표시하지 않는다.
- 각 채팅방 안에서 소스 메시지 ID로 중복 제거·수정을 처리하고 기존 앱 채팅은 덮어쓰지 않는다. 채팅방 사이에 같은 메시지 ID가 있어도 서로 덮어쓰지 않는다. 완전한 스냅샷은 분기·삭제를 반영해 소스 기억을 다시 정리한다. 수정 충돌은 버전으로 감지한다.
- 앱 → ChatGPT는 **ChatGPT로 이어가기 복사**로 마지막 앱 대화 40개를 복사한다. 사용자가 원본에 붙여 넣으며 자동 전송하지 않는다.

## 출력

프로젝트 지침의 사건·성격을 유지하되 채팅/음성의 출력 형식은 앱 규칙을 우선한다. 지문과 다른 화자의 대사를 제거하고 음성은 자음 웃음·이모지·주요 채팅 축약어를 구어체로 바꾼다. 실시간 응답·일반 답장·선톡·연속 선톡·TTS 모두 같은 전용 기억과 출력 규칙을 적용한다.

앱 전용 말투는 지우의 장난스러움을 유지하면서 행동 지문에 담긴 배려를 직접 하는 말로 옮긴다. 애정이나 다정함 요청에 튕기거나 비꼬는 반응, 끝에서 다정함을 취소하는 말은 줄인다. 이 보정은 `projectMediumPrompt`에만 있으며 ChatGPT 원본 지침·대화와 저장된 사건 기억을 수정하지 않는다. 대화내용 업데이트 뒤에도 같은 앱 규칙을 적용한다. 음성은 승·v3를 유지하고 자음 웃음 없이도 부드러운 입말을 생성한다.

## 검증

`node --test tests/project-context.test.mjs tests/reply-jobs.test.mjs tests/voice-recovery.test.mjs`

일반 빌드는 합성 테스트만 실행한다. 커밋 메시지의 `[verify-jiwoo]`를 명시한 배포는 내부 검증 서버에서 실제 캐릭터·소스 읽기·인증/출처 차단·대화 생성·승 TTS를 확인한다. 사용자 기록에 테스트 메시지를 저장하지 않으며 로그인 비밀값·원문·오디오를 로그에 남기지 않는다. 공급자 과금·잔액 오류는 우회하지 않는다.

## 여러 채팅방 업데이트

- `docs/jiwoo-multiple-sources.sql`은 기존 테이블에 `sources`를 추가한다. 기존 01 메시지·요약은 보존하며 이전 클라이언트와도 호환한다.
- 채팅방마다 메시지, 요약, 해시, 전체/부분 상태와 확인 시각을 따로 저장한다. 02 전체 가져오기가 01·03을 삭제하지 않는다.
- 기본 버튼은 지정한 순서로 각 방을 읽고 저장한다. 일부 실패 시 성공한 방을 보존하고 실패한 방과 기존 기억 유지 사실을 표시한다. 방별 버튼과 수동 가져오기 대상 선택도 제공한다.
- 프롬프트는 설정된 방 순서로 요약을 읽고 가장 최신 방의 최근 대화만 붙인다. 가져온 날짜와 극중 시간은 다르다. 현재 세계관은 최신 방에서 확인된 시간 경과·학적을 따르며 초기 고2 고정 문구로 되돌리지 않는다. 과거 미성년 시절은 당시 비성적 과거로만 다룬다.
- ChatGPT의 프로젝트 내부 메모리를 직접 조회하는 기능이 아니다. 지정된 프로젝트 대화와 이 캐릭터의 앱 기록만 사용한다.
- 연결 프로그램 1.1.1은 프로젝트 이름에 따른 URL 리디렉션을 정규화하고 화면에 보이는 대화 영역만 읽는다. 캐시된 다른 채팅방의 숨겨진 영역은 제외한다. 기존 설치는 파일 교체·확장 프로그램 새로고침·앱 새로고침이 필요하다.

1.1.1은 sender.url로 출처를 검증해 tabs 권한 없이 동작한다. 연결 확인은 실행 중인 서비스 워커의 버전·프로토콜 응답을 사용하며, 오래된 콘텐츠 스크립트의 먼저 온 응답은 새 응답을 가리지 않는다. URL 이름 변경과 같은 대화 영역의 재생성도 허용하고, 본문 로딩 중인 메시지가 있으면 전체 기록으로 표시하지 않는다.
