# 지우 프로젝트 연결

지우는 기존 캐릭터를 바꾸지 않고 별도 DB 행으로 추가한다. 지침과 대화 원문은 비공개 DB에만 저장하며 저장소에 넣지 않는다. 고2 세계관을 현실 사용자 프로필과 분리한다.

## 이어받기

- 지우 화면의 **대화내용 업데이트**는 PC 크롬 연결 프로그램을 통해 연결된 ChatGPT 대화의 화면 텍스트를 읽는다. ChatGPT 비공개 API·인증 쿠키·비밀번호는 사용하지 않는다.
- 최초 설치가 필요하다. `npm run build` 전에 연결 프로그램 ZIP이 자동 생성되며 `/jiwoo-project-bridge.zip`에서 내려받을 수 있다.
- 아이폰 단독 자동 가져오기는 지원하지 않는다. PC에서 반영한 맥락은 아이폰에서도 같은 서버 기억을 사용한다. JSON·화자 구분 TXT 수동 가져오기도 제공한다.
- 현재 연결 대상은 한지우 프로젝트의 ‘대화 시작’이다. 다른 프로젝트·계정·채팅을 임의로 검색하지 않는다.
- 전체 로드에 실패하면 최근 창만 반영했다는 상태를 명시한다. 불완전한 화면을 전체 기록으로 표시하지 않는다.
- 소스 메시지 ID로 중복 제거·수정을 처리하고 기존 앱 채팅은 덮어쓰지 않는다. 완전한 스냅샷은 분기·삭제를 반영해 소스 기억을 다시 정리한다. 수정 충돌은 버전으로 감지한다.
- 앱 → ChatGPT는 **ChatGPT로 이어가기 복사**로 마지막 앱 대화 40개를 복사한다. 사용자가 원본에 붙여 넣으며 자동 전송하지 않는다.

## 출력

프로젝트 지침의 사건·성격을 유지하되 채팅/음성의 출력 형식은 앱 규칙을 우선한다. 지문과 다른 화자의 대사를 제거하고 음성은 자음 웃음·이모지·주요 채팅 축약어를 구어체로 바꾼다. 실시간 응답·일반 답장·선톡·연속 선톡·TTS 모두 같은 전용 기억과 출력 규칙을 적용한다.

## 검증

`node --test tests/project-context.test.mjs tests/reply-jobs.test.mjs tests/voice-recovery.test.mjs`

일반 빌드는 합성 테스트만 실행한다. 커밋 메시지의 `[verify-jiwoo]`를 명시한 배포는 내부 검증 서버에서 실제 캐릭터·소스 읽기·인증/출처 차단·대화 생성·승 TTS를 확인한다. 사용자 기록에 테스트 메시지를 저장하지 않으며 로그인 비밀값·원문·오디오를 로그에 남기지 않는다. 공급자 과금·잔액 오류는 우회하지 않는다.
